# NuclearCSS

A tiny atomic CSS framework inspired by [UnoCSS][u] with a partially
[TailwindCSS v4][t]-compatible class API.

Both TailwindCSS and UnoCSS focus on integrations with limited
programmatic APIs.  This made it hard to integrate them into my SSG, so
that's how NuclearCSS came to be.


[u]: https://unocss.dev/
